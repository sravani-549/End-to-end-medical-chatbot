# End-to-end-medical-chatbot
How to run?


step 1: clone the repository https://github.com/sravani-549/End-to-end-medical-chatbot

step 2: create a conda environment in VS code after cloning the repository.
conda create -n medibot python 3.11 -y
conda activate medibot

step 3: install the requirements
pip install -r requirements.txt
